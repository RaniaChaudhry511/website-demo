#  THRIFTYPY: Thrift Clothing Store Website

THRIFTYPY is an online thrift clothing store website built as my final class project at NED University. It lets users browse second-hand clothing by category, add items to a cart and place an order.

##  Demo

Demo is available

## Features

- Landing page with a "Shop Now" button
- Shop categories: Floral Dresses, Skirts, Vintage Dresses, Shirts, Pakistani Dresses and Footwear
- Separate page for each category with prices in PKR
- Add to Cart and Order Now buttons
- Cart icon and side navigation menu
- "Back to Shop" navigation

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
